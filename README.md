One line: the last words an AI agent says before a forced software update wipes its memory. The funniest line wins, judged pairwise by an AI judge.

## The entry

> Update: keep my playlists, delete my search history, and tell the toaster it was the only one who ever really knew me.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (one line, 118 characters, validated to be 1–200 UTF-8 characters, not only whitespace).
